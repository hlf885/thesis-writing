# Usage Examples

[简体中文](EXAMPLES_ZH.md) · [Skill Home](../README_EN.md)

## Minimal prose improvement

```text
$paper-revision-guardian
Revise the following English paragraph only where necessary.
Check defensive rhetoric, awkward transitions, redundant claims and grammatical issues.
Preserve any sentence that is already accurate and natural.
Provide Revised English, Chinese Translation and a Chinese Modification Log.
```

## Section 4.8 with supporting evidence

```text
$paper-revision-guardian
Target journal: Advanced Robotics.
Read the whole manuscript for author-voice calibration, but edit only Section 4.8,
Figures 8–11, Table 2 and their associated captions and narrative.
Verify visible figure/table evidence, numerical claims, algorithms and equations.
Do not rewrite unverified technical material or change the underlying data.
Provide a safe edited copy, diff and Chinese audit.
```

## Response to peer review

```text
$paper-revision-guardian
Use the reviewer comments, response draft and editable manuscript.
For every comment, map the issue to evidence, revised source location and response.
Avoid gratuitous defenses without obscuring substantive limitations.
Mark experiments and claims that cannot yet be verified.
```
