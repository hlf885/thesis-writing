# 使用示例

[English](EXAMPLES_EN.md) · [Skill 首页](../README.md)

## 单段英文最小润色

```text
$paper-revision-guardian
对以下英文段落进行最小必要润色。判断是否存在防御性写作、逻辑重复、机械连接词和非母语表达；无问题则保留原句。
输出 Part 1 修订英文、Part 2 中文直译、Part 3 中文修改记录。
```

## 研究叙事与贡献主线审校（仅修改指定文字）

```text
$paper-revision-guardian
请阅读全文建立原作者的行文风格基线，但只修改我指定的英文章节。
重点检查研究问题与贡献主线是否连贯、核心机制是否解释充分、
是否存在开发日志式叙述、空泛创新宣传和重复防御，
以及结果描述与讨论解释是否混淆。
保持专业术语、句法习惯和技术含义；能保留的好句子不要重写。
只进行必要的文字修改，不要求补实验或重新计算统计结果。
交付修订文本、中文直译及中文修改理由。
```

## 只检查、不修改任何文件

```text
$paper-revision-guardian
本次只检查我指定的段落，不修改任何文件。
请依据原作者风格、贡献主线和机制解释要求，
报告真实存在的写作问题及建议，并区分必须修正与可选优化。
不要对原文作未经授权的改写。
```

## 4.8 节与图表同步审校

```text
$paper-revision-guardian
目标期刊为 Advanced Robotics。
阅读全文建立写作风格基线，但仅处理第 4.8 节、Figure 8–11 和 Table 2 及对应图注表注。
核查可见图表、正文引用数值、实验条件、公式和算法。
对未经证实的技术问题仅记录，不更改原始数据。
保留原稿，交付 diff、修订版和中文审计报告。
```

## 正式返稿与审稿人意见

```text
$paper-revision-guardian
读取审稿意见、我的回应草稿与论文源文件。
逐条建立 reviewer comment、证据、修改位置和回应的对应关系。
避免不必要的自我辩解，但必须完整回应真实问题。
将未完成的实验和无法验证的内容标记出来。
```
