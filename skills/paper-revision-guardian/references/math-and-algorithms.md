# Mathematical and Algorithmic Verification

Check notation, definitions, symbol reuse, dimensions, coordinate frames, domains, units, assumptions, constraints, index bounds, boundary cases and logical validity of derivation. Check whether convergence, stability, optimality and complexity claims follow from stated assumptions and implementation.

For pseudocode inspect input, output, initialization, update ordering, loop and branch semantics, termination, intermediate state and return values. Match pseudocode with numbered formulas and actual implementation where available. Preserve necessary numbered procedural stages.

Freeze all original formulas by default. If a technical fault is demonstrated, document its location, evidence, implications and suggested correction; change only when authorized and verified. Never guess a missing numerical value or assume a paper's algorithm was executed without running it.
