# Reviewer-response traceability

Create an explicit mapping: reviewer concern -> evidence -> manuscript location -> change made -> response paragraph. Be respectful, factual and concise without automatic concessions or evasive rhetoric. If reviewers identified an actual problem, address it with verifiable evidence and disclose remaining limitations. Do not promise new experiments as already completed. Preserve the source claim and reviewer requirement, and explain unresolved issues separately.

When comments or final manuscript are unavailable, do not invent correspondence or pretend a response is complete.
